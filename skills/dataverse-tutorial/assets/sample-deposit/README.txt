Dataverse tutorial: synthetic temperature observations

All station identifiers and measurements in observations.csv are invented
for this local practice exercise. They are not research results.

Columns:
- station: synthetic station identifier
- date: observation date in YYYY-MM-DD form
- temperature_c: temperature in degrees Celsius

No missing values are present in this sample. The file is UTF-8 CSV with a
header row. The accompanying sample-draft.json represents an offline,
un-ingested draft inventory with both files labeled under the data folder.
It is not a response from a real Dataverse installation.
